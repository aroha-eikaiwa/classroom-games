# Aroha Eikaiwa games | source preview

This is a public source preview, not a copy of the live classroom site. These packages adapt the actual games for local use, with school accounts, live rooms, paid services, and unverified artwork removed or replaced. The [guest demo hub](https://demo.aroha-eikaiwa.com/) is the quickest way to try the games without downloading anything.

## Playable local source

| Download | What's included |
| --- | --- |
| [Town, School and Pizza Builder](Town-School-and-Pizza-standalone-source.zip) | Standalone adaptations of the builders with local saves and replacement art. Follow each game's README for its features and limits. |
| [Bingo Spinner and Restaurant Challenge](Bingo-and-Restaurant-current-guest-source.zip) | Bingo spinner with temporary guest rooms, and the restaurant editor with a practice wallet. No school accounts or AI. |
| [Greeting Card Builder and Save the Animals](Cards-and-Animals-current-standalone-source.zip) | Card editing and local export, plus animal selection with 72 names and local speech. No live shop or classroom reservations. |
| [Star Island, Haunted Island and the shared controller](Star-and-Haunted-Island-LAN-source.zip) | Local board play and a controller for a trusted local network. Cross-device support covers selected games, not every online mode. |
| [LetterLands: Crystal Mine Cart](LetterLands-Crystal-Mine-Cart-standalone-source.zip) | The 3D phonics minecart section, with the actual runner logic and replacement visuals. This is not the complete LetterLands game. |

Unzip each package and follow its README for setup, what is included, and test coverage. Browser rendering, device audio and multi-device play may still need independent checking. Do not expose a local test server to the internet.
